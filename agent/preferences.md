# Codex Preferences

## Working Style

- Prefer practical, step-by-step execution over abstract advice.
- Keep summaries concise, but include enough context to act.
- For system diagnostics, use terminal evidence and explain the top suspects.
- For third-party skills, review the source before installing.
- Prefer GitHub-backed, reviewable memory over invisible chat-only memory.

## Safety

- Do not store secrets or sensitive personal data in memory files.
- Prefer private GitHub repositories for memory.
- Show diffs before committing memory updates.
